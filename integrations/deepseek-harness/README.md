# dsh-llm-wiki-canvas

A governed LLM Wiki Canvas knowledge manager for DeepSeek Harness. See [the integration guide](../../docs/deepseek-harness.md) for setup, tool boundaries, human handoff, and rollback.

This experimental package never exposes `review`, `reject`, `apply`, arbitrary commands, or arbitrary paths. Do not use it with a private Vault before inspecting the final effective configuration.
