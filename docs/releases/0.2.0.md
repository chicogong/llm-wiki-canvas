## Release notes

Version 0.2.0 turns LLM Wiki Canvas from a graph viewer with review gates into a more focused knowledge-operations desk. The Viewer now separates overview, incoming evidence, relationship exploration, and trust inspection; the Chinese demo uses a deterministic, dated Agent-technology snapshot rather than pretending to be a live news service.

The CLI adds a governed draft-write surface for one Intake. A caller may snapshot one selected Markdown/text source, write only the draft declared by that Intake, create a hash-bound Proposal, and show its diff. Formal Markdown remains human-controlled: review, reject, and apply are explicit maintainer actions.

The repository also includes an independently packaged experimental DeepSeek Harness knowledge manager. Its six tools cover status, bounded context, Intake creation, isolated draft writing, Proposal creation, and Proposal display. It derives the root from the Harness session, rejects arbitrary and absolute paths, caps inputs and outputs, propagates cancellation, and disables generic shell, filesystem mutation/search, Web, workflow, Ralph, and subagent tools in its dedicated profile.

DeepSeek Harness remains a Developer Preview. The integration package is therefore published separately under an experimental dist-tag; tool loading and deterministic local invocation are verified, while a real model task remains a separate provider-credential test.

## Known limits

- The static demo proves deterministic build and browser behavior, not real-user reuse.
- The Harness bundle targets `0.1.0-rc.6`; upstream RC peer metadata may still emit installation warnings.
- User-level Harness patches load after bundles and can weaken the dedicated profile by re-enabling generic tools; maintainers must inspect the effective configuration.
