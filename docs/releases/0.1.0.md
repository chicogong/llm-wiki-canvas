## Release notes

Version 0.1.0 establishes a local-first, file-native knowledge workbench for Markdown and Obsidian. It compiles deterministic relationship graphs, editable Canvas and Excalidraw artifacts, bounded Agent context, governed source intake, and hash-bound human-reviewed proposals. Its evidence-cartography Viewer distinguishes the synthetic static Atlas from the loopback-only live Workbench. Repository Skills support Codex, Claude Code, Qoder, TRAE, and Tencent WorkBuddy without requiring MCP.

The 0.8 OKF Trust work adds Open Knowledge Format v0.2 checking and display for provenance, generated/verified actors, lifecycle, freshness, sources, and Attested Computation contracts. The Workbench shows origin, review, freshness, and checker findings without inventing a composite trust score. Attested Computation remains descriptive: the product never executes bundle SQL, Python, Skills, attesters, executors, or external commands.

Release-candidate gates include strict ISO 8601 validation, timestamp-based latest-verification selection, a pinned official OKF bundle regression, unknown-field preservation, desktop/mobile production E2E, package installation smoke tests, generated third-party notices, and Linux/macOS package CI on supported Node.js 22 and 24 LTS releases.

Known limits:

- This is an OKF v0.2 consumer and checker, not the canonical validator.
- It does not implement attestation execution, receipt verification, an attester ABI, or sandboxing.
- A declared `verified` event is surfaced as bundle metadata, not treated as external identity proof.
- The pinned official Acme Retail bundle has frontmatter in `log.md`; the checker intentionally reports the normative reserved-file violation.
