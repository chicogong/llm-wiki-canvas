# Agent Skills 官方概览

核对日期：2026-08-14。

官方概览说明，一个 Skill 的核心是包含 `SKILL.md` 的目录，至少声明名称与描述，也可以包含脚本、参考资料、模板和其他资源。

加载过程分为发现、激活和执行三个阶段，完整说明只在任务匹配时进入上下文。

关联概念：[[../concepts/Agent Skills]]。
