# MCP 官方介绍

核对日期：2026-08-14。

官方文档把 MCP 描述为连接 AI 应用与外部系统的开放标准，覆盖本地文件、数据库、搜索工具和专门工作流等能力。

协议适合需要清晰客户端/服务器边界的集成，但并不意味着每个本地 CLI 都需要再包装一层 MCP。

关联概念：[[../concepts/MCP]]、[[../concepts/证据边界]]。
